## Application boundary
Your backend authenticates the caller, checks entitlement to a fixed stream and calls `relay.streams.getPlayback(id)` for status. It calls `relay.streams.createPlaybackGrant(id)` to grant viewing. Neither endpoint should become an unauthenticated arbitrary management proxy. Return metadata from a same-origin status endpoint and a grant from an authenticated POST endpoint. For cookie authentication, enforce your trusted Origin on mutations.

A grant contains `{ url, token, expiresAt }`. Default TTL is 300 seconds; supported range is 30..3600 seconds. The grant URL authorizes that stream/source session. Refresh by issuing another grant before expiry. Stop, deletion, configuration changes and explicit revocation invalidate old grants. Every child playlist, init object, segment and part is authorized, not only the first playlist.

## Browser and React
Use [StreamPlaybackClient](/reference/sdk/client/javascript/stream-playback) or [BroadcastPlayer](/reference/sdk/client/react/broadcast-player). Provide stable `getPlayback(signal)` and `getGrant(signal)` callbacks to application endpoints. The client polls at five-second intervals, refreshes grants twenty seconds before expiry and reloads on source session/generation changes. Status polling reconciles after reconnect without a new signaling channel.

Native HLS is used when supported. Else provide an optional application-owned HLS engine factory such as the hls.js adapter shown in the React reference. The player exposes loading, playing, paused, blocked, unavailable, unsupported and error states. Autoplay may require mute or a user gesture. Missing media waits for a live source; an explicit retry renews access. Unmount stops polling, aborts requests, clears media and destroys the engine.

## Delivery
The API supports query tokens for native HLS and Authorization Bearer where headers are available. Child references retain authorization. Responses are private/no-store with no-referrer and exact-origin CORS. Configure browsers, proxies and analytics to avoid recording token-bearing URLs. No shared CDN cache or public bucket is enabled.

The gateway delivers one fMP4 rendition with baseline HLS and LL-HLS parts/blocking reload. HTTPS, proxy timeouts, player support and source encoding affect latency. There is no numeric latency promise. Live-window snapshots are diagnostic storage, not VOD/DVR. Source changes may rebuffer. Only actual server observations drive source usage; browser player events do not establish billable audience traffic.
