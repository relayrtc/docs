Use text messages for chat, custom events for transient actions, and participant metadata for state that should appear in presence snapshots. These features travel through signaling; they do not require a media data track.

## Text messages

The sender's token needs `messages:send`. Render this component inside a connected `RelayRoom`:

```tsx
'use client'

import { useState } from 'react'
import type { FormEvent } from 'react'
import { useMessages, useRoom } from '@relayrtc/react'

export function Chat() {
  const { messages, send } = useMessages()
  const { connectionState } = useRoom()
  const [text, setText] = useState('')
  const [pending, setPending] = useState(false)
  const [error, setError] = useState<string | null>(null)

  async function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault()
    setPending(true)
    setError(null)
    try { await send(text); setText('') }
    catch (cause) { setError(cause instanceof Error ? cause.message : 'Message could not be sent') }
    finally { setPending(false) }
  }

  return (
    <section>
      <ul>{messages.map(message => <li key={message.messageId}>{message.text}</li>)}</ul>
      <form onSubmit={event => void submit(event)}>
        <label>Message <input value={text} maxLength={4000}
          onChange={event => setText(event.target.value)} /></label>
        <button disabled={pending || connectionState !== 'connected' || !text.trim()}>Send</button>
      </form>
      {error && <p role="alert">{error}</p>}
    </section>
  )
}
```

Messages accept up to 4,000 characters; whitespace-only messages are rejected. The provider retains 100 messages locally by default. `messageHistoryLimit` changes that local retention limit, not server storage. `clear()` clears only your local history. Reloading the page does not restore durable chat history.

## Custom events

Custom events also require `messages:send`. Emit a named JSON payload, then subscribe to received events. The subscription returns a cleanup function for the React effect.

```tsx
'use client'

import { useEffect, useState } from 'react'
import { useRoom } from '@relayrtc/react'

export function Reactions() {
  const { room, connectionState } = useRoom()
  const [reaction, setReaction] = useState('')
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    if (!room) return
    return room.events.subscribe(event => {
      if (event.name === 'reaction.sent' && typeof event.data === 'string') setReaction(event.data)
    })
  }, [room])

  async function react() {
    if (!room) return
    setError(null)
    try { await room.events.emit('reaction.sent', 'wave') }
    catch (cause) { setError(cause instanceof Error ? cause.message : 'Reaction could not be sent') }
  }

  return <div>
    <button disabled={!room || connectionState !== 'connected'} onClick={() => void react()}>Wave</button>
    <p role="status">{reaction}</p>
    {error && <p role="alert">{error}</p>}
  </div>
}
```

Names start with a lowercase letter and contain at most 64 lowercase letters, digits, underscores, dots or hyphens. Payloads must be JSON values. Events are transient; do not use them as your only record of an administrative decision or durable transaction.

## Raised hands

Use metadata for participant state that should be included in presence snapshots. The participant needs `metadata:update` to update their own metadata.

```tsx
'use client'

import { useState } from 'react'
import { useLocalParticipant, useParticipants, useRoom } from '@relayrtc/react'

export function RaisedHands() {
  const local = useLocalParticipant()
  const participants = useParticipants()
  const { connectionState } = useRoom()
  const [error, setError] = useState<string | null>(null)

  async function toggle() {
    if (!local) return
    setError(null)
    try {
      await local.updateMetadata({ ...local.metadata, handRaised: local.metadata.handRaised !== true })
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : 'Hand state could not be updated')
    }
  }

  return <div>
    <button disabled={!local || connectionState !== 'connected'} onClick={() => void toggle()}>
      {local?.metadata.handRaised === true ? 'Lower hand' : 'Raise hand'}
    </button>
    <ul>{participants.map(person => <li key={person.id}>
      {person.name}{person.metadata.handRaised === true ? ' (hand raised)' : ''}
    </li>)}</ul>
    {error && <p role="alert">{error}</p>}
  </div>
}
```

Metadata updates replace the object. Preserve existing fields when you intend to keep them. Metadata is participant-controlled application state, not authority: do not grant moderator permissions because a participant sets a `role` field in it.
