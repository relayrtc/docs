Start with the visible symptom, SDK state and safe error code. REST administration, signaling, capture, media connectivity, subscription and playback are separate stages. Avoid recreating the room while investigating a later stage.

## Signaling fails

Use the WebSocket signaling URL, not the REST API address. The default local address is `ws://localhost:8081/v1/connect`; remote browsers need a reachable host, and HTTPS frontends should use secure WebSockets.

Check signaling's allowed origins. A different scheme, hostname or port is a different origin. Then check token expiry, room identity and `room:join` permission. Log request/error identifiers without logging the token.

## Participants appear but media does not

Check these in order:

1. Is the publisher connected, with a captured track and the required publication permission?
2. Does the receiver see the remote publication in `useTracks`?
3. What is the remote track's subscription state and `useMediaTrack` playback state?
4. Can each browser reach the announced media address and, if needed, the TURN service?
5. Does browser WebRTC diagnostics show a selected ICE pair and received bytes?

A container-only address or stale host LAN address can break media while REST and signaling remain healthy. Use [TURN diagnostics](/guides/turn-configuration#check-the-connection) for restrictive networks.

## Autoplay is blocked

When `useMediaTrack` reports `blocked`, render a play button and call its `play()` method from that click. Keep the element attached and show subsequent failures. Repeating automatic play calls cannot substitute for a required user gesture. See the [quickstart renderer](/quickstart#connect-from-react).

## Camera remains frozen after camera-off

Use `camera.disable()` to release capture and remove its publication. Use `mute()` to keep capture open and pause sending; current mute/unmute calls wait for server confirmation and signal the remote publication state.

A remote tile should show a placeholder when `useMediaTrack(...).isPaused` is true or when no camera publication exists. Do not keep a frozen frame visible as if the camera were still live.

## Capture is denied or a device disappears

Confirm HTTPS or localhost, browser site permissions, operating-system device access and the presence of a usable device. An `exact` capture constraint can fail even when a different resolution works. Show the rejection near the control and let the user change permissions or devices before retrying.

## Screen audio is missing

Display audio depends on browser, operating system and selected surface. Inspect `screen.audioTrack`; `audio: true` is a request, not a guarantee. Render remote `screen_audio` in a separate audio element rather than assuming it is mixed into microphone audio.

## Media takes several seconds to appear

Measure capture, negotiation, subscription and first-frame arrival separately. Loading state describes those stages; it is not evidence that the server has finished delivery. Check network conditions, selected route, available source layers and actual received dimensions.

## Recovery fails

Inspect `RoomError.code`, connection state and credential expiry. An ended room, removed participant or lost runtime state may require a fresh authorized join. A token for another participant cannot renew the active identity.

For long-running calls, verify both participant-token and TURN renewal paths. Returning an authorization denial must end access rather than trigger an endless retry. See [connection recovery](/guides/connection-recovery).

## Streaming playback

RTC tracks and HLS playback use different delivery paths. For streaming, inspect source state, viewer readiness and the pending operation. A connected publisher or newly issued grant does not prove the manifest is ready.

Reissue expired/revoked grants through an authenticated application endpoint. Inspect codecs, selected source tracks and deployment health before retrying a start operation. See [private playback](/guides/streaming-playback) and [streaming deployment](/guides/streaming-self-hosting).
