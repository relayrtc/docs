## Your first room

Your server creates a room and issues a participant token. The browser uses that token to connect, publish media and receive other participants.

1. Create a secret API key in your project environment.
2. Create a room with the REST API or Node SDK.
3. Issue a token for each participant.
4. Join from React and enable camera or microphone access.

Start with the [quickstart](/quickstart). It connects the server and browser in one flow.
