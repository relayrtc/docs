## Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `expiresAt` | string | Credential expiry timestamp. |
| `username` | string | Issued TURN username. |
| `ttlSeconds` | number | Credential lifetime in seconds. |
| `iceServers` | array | STUN/TURN RTCIceServer entries. |

## Example

```json
{
  "expiresAt": "2026-01-01T12:10:00.000Z",
  "username": "issued-turn-username",
  "ttlSeconds": 600,
  "iceServers": [
    {
      "urls": [
        "stun:turn.your-domain.example:3478"
      ]
    },
    {
      "urls": [
        "turn:turn.your-domain.example:3478?transport=udp"
      ],
      "username": "issued-turn-username",
      "credential": "issued-turn-password",
      "credentialType": "password"
    }
  ]
}
```

## ICE server entries

Each entry has `urls: string[]`. TURN entries also include `username`, `credential` and `credentialType: 'password'`. Pass the returned entries to browser ICE configuration; do not use the REST API key as a TURN password.
