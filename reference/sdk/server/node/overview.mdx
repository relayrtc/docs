## Install

<InstallTabs packages="@relayrtc/node" />

The package requires Node.js 22 or newer. See [installation](/installation) for setup instructions.

## Create a client

```ts
import { RelayServer } from '@relayrtc/node'

const relay = new RelayServer({
  apiUrl: process.env.RELAYRTC_API_URL!,
  apiKey: process.env.RELAYRTC_SECRET_KEY!,
})
```

Use a secret API key. The client normalizes the API URL to include `/v1`.

## Create a room and token

```ts
const room = await relay.rooms.create({ name: 'Team call' })
const issued = await relay.tokens.create(room.id, {
  participantName: 'Alice',
  permissions: ['room:join', 'audio:publish', 'video:publish'],
})
```

Send `issued.token` to that authenticated user. The browser joins with the React or browser SDK.

## Resources

| Client resource | Purpose |
| --- | --- |
| `context()` | Read API key context. |
| `rooms` | Create, list, read and end rooms; inspect cleanup. |
| `tokens` | Issue and renew participant tokens. |
| `participants` | List, read, remove and inspect cleanup. |
| `turn` | Create temporary TURN credentials. |
| `usage` | Read public usage categories. |
| `webhooks` | Manage endpoints and signing secrets. |
| `webhooks.deliveries` | Read delivery logs and replay. |
| [streams](/reference/sdk/server/node/streams) | Configure sources, ingest credentials, playback grants and source operations. |
| [broadcasts](/reference/sdk/server/node/broadcasts) | Create runs, inspect outputs and retry failed destinations. |
| [destinations](/reference/sdk/server/node/destinations) | Save external platform settings and rotate stream keys. |
| [recordings and assets](/reference/sdk/server/node/recordings) | Capture programs and issue private playback/download grants. |
| [schedules](/reference/sdk/server/node/schedules) | Plan events and issue event-scoped access. |
| [external sources](/reference/sdk/server/node/restream-sources) | Probe and control approved upstream inputs. |
| [clips](/reference/sdk/server/node/clips) | Configure buffers, render intervals and publish highlights. |
| [DVR](/reference/sdk/server/node/dvr) | Manage rolling retention and inspect run windows. |
| [mixers](/reference/sdk/server/node/mixers) | Save and activate server-rendered scenes. |
| [guest stages](/reference/sdk/server/node/guests) | Manage invitations, moderation and scoped stage grants. |

The Node SDK does not capture a camera or join a media call. It wraps the public management REST API.

## Request behavior

Successful data objects are returned directly. Errors throw [RelayApiError](/reference/sdk/server/node/RelayApiError).

Only GET requests retry automatically. Create, update, delete, secret rotation and replay requests are attempted once.

See [RelayServer options](/reference/sdk/server/node/RelayServer) and [request options](/reference/sdk/server/node/request-options).

## Streaming resources

[Stream management and operation methods](/reference/sdk/server/node/streams) add typed source configuration, encoder credentials and private playback grants. Use compatible API/SDK builds; see [installation](/installation). Streaming commands generate idempotency keys unless an explicit application command ID is supplied.


## Room access and audit history

Use [`participants.getAccess`, `participants.updateAccess` and `rooms.audit`](/reference/sdk/server/node/room-access) to administer versioned room roles, permission restrictions and immutable room history. Mutations require the new `participants:write` scope.
