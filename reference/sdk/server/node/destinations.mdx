---
title: "Node destination methods"
description: "Configure private platform connections and select them for broadcast runs."
section: "Node SDK"
---

Use the matching local SDK build on your authenticated application backend. Never send its secret API key or destination credentials to viewers.

```ts
const first = await relay.streams.destinations.create(streamId, {
  name: 'First platform', endpoint: platformServerUrl, streamKey: platformStreamKey,
  profile: 'remux',
})
const second = await relay.streams.destinations.create(streamId, {
  name: 'Second platform', endpoint: secondServerUrl, streamKey: secondStreamKey,
  profile: '720p',
})
const run = await relay.broadcasts.create({
  streamId, name: 'Live program', destinationIds: [first.id, second.id],
})
await relay.broadcasts.start(run.id)
```

| Method | Input/result |
| --- | --- |
| streams.destinations.create | streamId, configuration, options → StreamDestination |
| streams.destinations.list | streamId, optional cursor/limit, options → DestinationPage |
| streams.destinations.get | streamId, destinationId, options → StreamDestination |
| streams.destinations.update | streamId, destinationId, version plus changes, options → StreamDestination |
| streams.destinations.delete | streamId, destinationId, options → id/deleted |
| streams.destinations.rotateSecret | streamId, destinationId, version/streamKey, options → StreamDestination |
| broadcasts.outputs.retry | broadcastId, outputId, optional version, options → StreamingOperation |

```ts
const current = await relay.streams.destinations.get(streamId, first.id)
await relay.streams.destinations.update(streamId, first.id, {
  version: current.version, enabled: false,
})
const latest = await relay.streams.destinations.get(streamId, first.id)
await relay.streams.destinations.rotateSecret(streamId, first.id, {
  version: latest.version, streamKey: replacementKey,
})
const pending = await relay.broadcasts.outputs.retry(run.id, failedOutputId, {}, {
  idempotencyKey: stableApplicationCommandId,
})
const progress = await relay.streamingOperations.get(pending.id)
```

Management mutations generate an idempotency UUID unless provided. Preserve one key when retrying after a lost response. Returned resources never reveal saved endpoint paths or keys. Disabling/removing/rotating affects newly created runs; stop an existing run to disconnect its saved outputs. No platform account OAuth is performed. See [REST contracts](/reference/api/v1/destinations) and [setup guide](/guides/multistreaming).
