## Import

```ts
import { participantPermissions, webhookEventTypes } from '@relayrtc/node'
```

## Participant permissions

```ts
const permissions = [
  'room:join',
  'audio:publish',
  'video:publish',
  'screen:publish',
  'messages:send',
  'metadata:update',
] as const
```

The exported `participantPermissions` array contains these values. Tokens must include room:join. Grant only what the caller needs.

The exported `webhookEventTypes` array contains these values. Endpoint subscriptions must be nonempty and unique. The API validates the requested types; a subscription does not itself start a recording, schedule or other resource.

See the [event envelope and families](/reference/api/v1/schemas/webhook-event) for the REST catalog. The SDK also exports `ParticipantPermission` and `WebhookEventType` types.

Matching SDK builds also export `recordingEventTypes` and `scheduleEventTypes` as runtime arrays from the package root. They contain the recording and scheduled-broadcast subsets of this catalog.
