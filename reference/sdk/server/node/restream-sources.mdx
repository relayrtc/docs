---
title: "Node restream source methods"
description: "Manage approved external inputs from an authenticated application backend."
section: "Server SDK"
---

Use a matching local Node SDK with streams:read/write/publish. All mutations accept RequestOptions, including idempotencyKey for application-managed retries. Types include RestreamSource, RestreamDetail, RestreamSession, RestreamProtocol, RestreamState, CreateRestreamSourceInput and UpdateRestreamSourceInput.

```ts
const source = await relay.restreamSources.create({
  streamId, name: 'Approved feed', protocol: 'hls_pull',
  endpoint: process.env.APPROVED_HLS_URL!,
  redistributionAuthorized: true,
}, { idempotencyKey: crypto.randomUUID() })
await relay.restreamSources.probe(source.id)
const status = await relay.restreamSources.get(source.id)
if (status.state === 'ready') await relay.restreamSources.start(source.id)
const page = await relay.restreamSources.list({ limit: 30 })
await relay.restreamSources.stop(source.id)
// Wait for status.session.endedAt before updating credentials or limits.
await relay.restreamSources.update(source.id, {
  version: source.version, authorization: process.env.NEW_SOURCE_AUTHORIZATION!,
})
await relay.restreamSources.delete(source.id)
```

Registry URLs and headers stay on your backend. Issue push credentials with streams.createIngestCredentials; viewers only receive application-authorized playback grants. [External ingest](/guides/external-ingest) defines attachment rules and actual supported profiles. [REST contracts](/reference/api/v1/restream-sources) define async state and pagination.
