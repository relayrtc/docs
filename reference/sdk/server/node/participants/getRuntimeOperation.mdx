## Import and client

```ts
import { RelayServer } from '@relayrtc/node'

const relay = new RelayServer({
  apiUrl: process.env.RELAYRTC_API_URL!,
  apiKey: process.env.RELAYRTC_SECRET_KEY!,
})
```

## Requirements

A secret key with `participants:read`. The requested resource must belong to that key's project environment.

## Parameters

| Option | Type | Default / requirement | Purpose |
| --- | --- | --- | --- |
| roomId | string | Required | ID of a room in the key's environment. |
| participantId | string | Required | ID of a participant in this room. |

Every method accepts [RequestOptions](/reference/sdk/server/node/request-options) as its final argument.

## Example

```ts
const roomId = 'room_example'
const participantId = 'participant_example'
const result = await relay.participants.getRuntimeOperation(roomId, participantId)
```

## Returns

`Promise<RuntimeOperation>`. Returns a [runtime operation](/reference/api/v1/schemas/runtime-operation). `404 OPERATION_NOT_FOUND` when no operation exists.

## REST equivalent

[`GET /v1/rooms/{roomId}/participants/{participantId}/runtime-operation`](/reference/api/v1/participants/runtime-operation). Failures throw [RelayApiError](/reference/sdk/server/node/RelayApiError).
