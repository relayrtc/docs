---
title: "useClip"
description: "Request and follow application-authorized highlights, then play their VOD assets."
section: "React SDK"
---

```tsx
const clip = useClip({
  getClip: signal => app.getClip({ signal }),
  create: context => app.createClip({ ...context, recordingId, interval: { kind: 'last', seconds: 30 } }),
  publish: context => app.publishClip(context),
  delete: context => app.deleteClip(context),
})
return <>
  <button disabled={!!clip.pending} onClick={() => { void clip.create() }}>Save last 30 seconds</button>
  <p>{clip.clip?.state}</p>
</>
```

Keep callback identities stable with useCallback and update them when selecting a different source/range. Command callbacks receive signal and idempotencyKey and return ClipResource; getClip returns ClipResource or null. Your backend authorizes the caller, resolves the allowed source, forwards the request key and stores the selected clip ID. Browser code must never receive a secret management key. The hook returns clip, pending, error, isReady, isProcessing, create, publish, delete and refresh. ClipClient exposes the same behavior without React. Polling is canceled on unmount; request revisions prevent stale poll results overwriting commands. An uncertain command retains its idempotency key for retry.

Range selection is application UI: use last-N seconds or numeric media boundaries from an authorized clip-window endpoint. The runnable streaming-foundation ClipPanel includes both. Display resolved segment boundaries for fast keyframe cuts, which can expand the interval. CLIP_RANGE_EXPIRED means the requested range is no longer fully retained.

Once ready, use BroadcastPlayer with mode: vod, metadata from recordings.getPlayback(clip.recordingId) and an authorized asset grant. HLS engines are application-provided as with other playback. Publication is required for viewer grants; hosts can use the explicit preview audience. Replaying a clip is finite VOD playback, separate from live DVR. See [clips and replay](/guides/clips-and-replay) for the example and operational limits.
