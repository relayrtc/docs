## Import

```tsx
import type { RoomRemoteTrack, UseTracksOptions } from '@relayrtc/react'

const options: UseTracksOptions = { types: ['camera_video'] }

function trackLabel(track: RoomRemoteTrack) {
  return `${track.participantId}: ${track.type}`
}
```

These types are exported from `@relayrtc/react`. The definitions below use supporting names from the browser SDK, protocol and React. You only need to import the public types your application uses.

## MediaTransportStats

One send or receive transport observation from [room.getMediaConnectionStats()](/reference/sdk/client/react/room#media-connection-stats). Exported by both `@relayrtc/client` and `@relayrtc/react`.

```ts
export interface MediaTransportStats {
  readonly direction: "send" | "receive";
  readonly state: RTCPeerConnectionState;
  readonly route: "direct" | "relay" | "unknown";
  readonly protocol: string | null;
  readonly relayProtocol: string | null;
  readonly bytesSent: number;
  readonly bytesReceived: number;
}
```

`route` reflects the selected ICE pair when connected. `protocol` is the candidate protocol; `relayProtocol` describes the browser-to-TURN transport when available. Either protocol can be null. An unknown route or zero byte counter without a selected pair is not proof that no traffic occurred.

## MediaConnectionStats

A snapshot for the local client's media transports. Exported by both `@relayrtc/client` and `@relayrtc/react`.

```ts
export interface MediaConnectionStats {
  readonly observedAt: string;
  readonly transports: readonly MediaTransportStats[];
}
```

`observedAt` is the ISO timestamp at which the SDK completed the observation. Snapshots do not update automatically; request another snapshot for a new reading.

## StreamPlaybackReadiness

Matching React SDK builds re-export `StreamPlaybackReadiness` from the browser client. Its fields are `status`, `publisherConnected`, `sourceProducing`, `outputStarting`, `viewerReady`, `code` and `checkedAt`. [Playback metadata](/reference/api/v1/streams#playback-metadata) defines each observation.

`StreamPlaybackMetadata.sourceState` and `readiness` are optional for application-owned playback callbacks. The API's stream endpoint supplies them, but a callback can return a smaller supported metadata object. They do not require joining an RTC room.

```ts
import type { StreamPlaybackMetadata } from '@relayrtc/react'

function isViewerReady(playback: StreamPlaybackMetadata) {
  return playback.readiness?.viewerReady ?? false
}
```

## Related field values

| Field | Values |
| --- | --- |
| Track type | `audio`, `camera_video`, `screen_video`, `screen_audio`; `data` is reserved and not supported for room media. |
| Subscription state | `unsubscribed`, `subscribing`, `subscribed`, `failed`, `closed` |
| Receive video preference | `auto`, `1080p`, `720p`, `360p`, `audio-only` |
| Connection quality | `excellent`, `good`, `poor`, `critical`, `lost` |
| Permission state | `granted`, `denied`, `prompt`, `unsupported` |

Quality statistics use seconds for round-trip time and jitter, and bits per second for bitrates. Browser-specific values can be null. See [connection quality](/reference/sdk/client/react/hooks/useConnectionQuality).
