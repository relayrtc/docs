The RelayRTC installer walks you through local or server configuration and creates a `relayrtc` folder with everything needed to start the stack. Rooms, streaming, PostgreSQL, mediasoup, coturn, private storage and monitoring are included.

## 1. Start Docker

Install Docker and Docker Compose. On Windows or macOS, open Docker Desktop and use Linux containers. On Linux, start Docker Engine. Use Engine 26 or newer and Compose v2 with a Linux AMD64 or ARM64 engine.

Choose a folder where you want to keep the installation. You do not need Node.js, pnpm, npm, Bun, Go, Git or a source ZIP.

## 2. Run the installer

Run the command for your terminal from that folder. The installer creates a `relayrtc` subfolder.

### macOS or Linux

```bash
docker run -it --rm -p 127.0.0.1:9095:9095 -v /var/run/docker.sock:/var/run/docker.sock -v "$(pwd):/setup/state" relayrtc/relayrtc:latest
```

### Windows PowerShell

```powershell
docker run -it --rm -p 127.0.0.1:9095:9095 -v /var/run/docker.sock:/var/run/docker.sock -v "${PWD}:/setup/state" relayrtc/relayrtc:latest
```

### Windows Command Prompt

```bat
docker run -it --rm -p 127.0.0.1:9095:9095 -v /var/run/docker.sock:/var/run/docker.sock -v "%cd%:/setup/state" relayrtc/relayrtc:latest
```

The image runs its `install` entrypoint automatically. Docker downloads it from Docker Hub. The Docker socket lets the installer inspect Docker and prepare the Compose configuration. Application services start only when you run Compose afterward.

For rootless Docker, replace the source socket path with your engine's actual socket. Git Bash may require disabling automatic path conversion. PowerShell and Command Prompt avoid that path-conversion behavior on Windows.

## 3. Complete the setup wizard

Open the private `http://localhost:9095/#token=...` link printed in the terminal. Use the complete link to authenticate your setup session. The wizard uses the RelayRTC console's design.

1. **Addresses.** Keep the localhost defaults or enter your public hostname or IP. Console, API and signaling share that hostname by default. Separate addresses are available under the optional advanced section. Add any other browser application origins.
2. **Media.** Configure the mediasoup announced hostname or IP and coturn public IP. Local defaults work for callers on this computer. Advanced settings expose the mediasoup port range and worker count.
3. **Integrations.** Configure Resend, GitHub and Google, or choose **Skip** for each integration.
4. **Review.** Check your settings and select **Generate configuration**.

PostgreSQL is included and fixed as the database. Infrastructure passwords, signing keys, encryption keys, storage credentials and TURN secrets are generated automatically. You do not create an administrator account in this wizard.

Skipping Resend disables email delivery and skips email verification. Signup and password login remain available. Password-reset emails, email changes and email invitations are unavailable until email is configured. GitHub and Google buttons appear only for configured providers.

Your settings are saved to `relayrtc/.env` and `relayrtc/docker-compose.yml`. Keep the entire folder private and preserve it across restarts. Select **Finish setup** to close the temporary installer and return to your terminal.

## 4. Start RelayRTC

From the folder where you ran the installer:

```sh
cd relayrtc
docker compose up -d --remove-orphans
```

Compose downloads the matching service images, initializes PostgreSQL and storage, runs migrations and starts rooms, streaming and monitoring. The installer image's `latest` tag resolves to a bundled release. Generated service images are pinned to that release rather than following `latest` independently.

Inspect startup:

```sh
docker compose ps -a
docker compose logs --tail=100 api console migrate
```

The stack contains 16 services. `migrate` and `streaming-storage-init` exit with code 0 after successful initialization. The remaining services should be running, with healthy status where health checks are configured.

## 5. Open the console

For local setup, open [http://localhost:3002](http://localhost:3002). Create your account, organization and project through the normal console flow.

Create a secret API key in **Developer Controls > API keys**. Keep it in your backend. For the [first call](/quickstart), grant `rooms:create` and `tokens:create`.

| Setting | Local default |
| --- | --- |
| Console | `http://localhost:3002` |
| API base | `http://localhost:8080/v1` |
| Signaling | `ws://localhost:8081/v1/connect` |
| RTMP ingest | `rtmp://localhost:1935` |

Streaming is already included. Continue with [publishing a stream](/guides/streaming-ingest) or [broadcasts](/guides/broadcasts).

## Server hosting

For a remote server, keep the wizard bound to loopback. Forward its port from your computer with `ssh -L 9095:127.0.0.1:9095 your-user@your-server`, then open the private link printed by the installer. This keeps setup credentials inside the SSH connection.

Public console/API/signaling addresses need DNS, trusted HTTPS and WebSocket proxying. A domain entered in the wizard does not provision certificates or open firewall ports. Media, TURN and ingest need their own reachable ports. See [public hosting](/guides/self-hosting-operations#public-hosting-and-ports).

## Stop, configure and maintain

Use Compose from your generated `relayrtc` folder. See [operations](/guides/self-hosting-operations) for settings, backups, shutdown and upgrades, and [sign-in and email](/guides/self-hosting-authentication) for optional providers.

For source development, `pnpm docker:up` remains available in a source checkout.
