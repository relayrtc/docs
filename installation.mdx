Install a frontend SDK in your browser application and the Node SDK in your backend. Running these packages does not start RelayRTC services; connect them to an existing deployment or [self-host RelayRTC](/self-hosting).

## Packages

| Package | Runs in | Use it for |
| --- | --- | --- |
| `@relayrtc/react` | React frontend | Providers, room hooks and media components. |
| `@relayrtc/client` | Browser | Room connections, devices, publications and subscriptions. Required alongside the React SDK. |
| `@relayrtc/node` | Node.js backend | Room administration, participant tokens and webhook verification. |

Shared types, validation and protocol packages support these SDKs. You do not need to install them separately for the first-call example.

## React

Use React 18.3.1 or 19 in your application. Install both the React wrapper and browser client:

<InstallTabs packages="@relayrtc/react @relayrtc/client" />

```tsx
import { RelayProvider, RelayRoom, useRoom } from '@relayrtc/react'
```

In Next.js, RTC providers and hooks belong in a `'use client'` module. Keep server-side token issuance in a separate backend module. Camera and microphone access require HTTPS or localhost and browser permission.

## Node.js

Use Node.js 22 or newer. The SDK is an ES module and includes TypeScript declarations.

<InstallTabs packages="@relayrtc/node" />

```ts
import { RelayServer, verifyWebhookRequest } from '@relayrtc/node'
```

For JavaScript, use `.mjs` files or set `"type": "module"` in your application's package manifest. Configure a secret project-environment API key on the server; never import this configuration into a frontend bundle.

## Plain browser client

Use the browser client directly if you do not use React or want to manage media elements yourself.

<InstallTabs packages="@relayrtc/client" />

```ts
import { RelayClient } from '@relayrtc/client'
```

See the [browser reference](/reference/sdk/client/javascript/overview) for joining, subscriptions and teardown.

## Package and server compatibility

The published baseline is React and Node `0.1.0` with browser client `0.0.0`. The published React package's browser-client peer range is `^0.0.0`. These version numbers do not identify every feature now present in source.

Newer interfaces, including Node `tokens.renew` and the streaming SDK families, require a matching newer SDK and server build. They are not available simply by installing the current baseline. Check a feature's compatibility requirements before adopting it, and upgrade the React wrapper and browser client together when their peer ranges change.

The REST path `/v1` is an API contract version, not an npm package version. Do not append an SDK version to the API URL.
